# Perpetual Medtech

A modern healthcare technology website built for Perpetual Medtech.

The project includes a responsive frontend, FastAPI backend, PostgreSQL database integration, dynamic product loading, and a functional contact form.

## Features

- Responsive healthcare website
- Modern UI/UX
- Mobile navigation
- Dynamic product loading from PostgreSQL
- Contact form connected to PostgreSQL
- FastAPI REST API
- PostgreSQL database integration
- Environment variable configuration
- CORS configuration
- API documentation with Swagger
- Git and GitHub version control

## Technology Stack

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Python
- FastAPI
- Uvicorn
- Pydantic

### Database
- PostgreSQL

### Development Tools
- Visual Studio Code
- Git
- GitHub
